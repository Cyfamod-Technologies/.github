# Security Policy

Cyfamod Technologies values responsible security research and reports made in good faith.

## Reporting a vulnerability

Do **not** open a public GitHub issue for a suspected security vulnerability.

Email **info@cyfamod.com** with the subject:

```text
Security report: <repository or product name>
```

Include, where safely possible:

- the affected repository, component or URL;
- the type and potential impact of the issue;
- clear reproduction steps or a minimal proof of concept;
- relevant logs or screenshots with secrets and personal data removed;
- suggested remediation, if available;
- a safe contact method for follow-up.

## Please avoid

- accessing, changing or deleting data that is not yours;
- service disruption, denial-of-service testing or destructive activity;
- social engineering, phishing or physical-security testing;
- exposing credentials, personal data or customer information;
- public disclosure before Cyfamod has had a reasonable opportunity to investigate and respond.

## Response

We will acknowledge actionable reports when possible, investigate based on severity and available information, and coordinate remediation and disclosure where appropriate. This file does not create a bug-bounty commitment or guarantee payment.
