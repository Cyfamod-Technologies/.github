# Support

## Open-source project help

For usage questions, suspected bugs and feature ideas:

1. Read the repository README and documentation.
2. Search existing issues.
3. Open the appropriate issue form in the affected repository and include enough detail to reproduce or understand the request.

Please do not use public issues for credentials, personal information, customer data or security vulnerabilities.

## Security reports

Follow [`SECURITY.md`](./SECURITY.md).
